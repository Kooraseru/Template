# Security Policy

Do not report vulnerabilities in issues, discussions, pull requests, or other
public channels.

Use **Security ➜ Report a vulnerability** in this repository to open a private
security advisory. Include the affected version, impact, reproduction details,
and any known mitigations. Maintainers will acknowledge a complete report as
soon as practical and coordinate disclosure after a fix is available.

Only the latest stable release is assumed to receive security fixes unless a
project documents a broader support window.
