# Repository content

`docs/` supplies the Pages site. `files/` supplies files placed at the root of
published repository branches. `i18n/` contains matching locale records.

`packages/` owns GitHub Packages records and descriptions. `releases/` owns
release records and notes. `ci/` contains authored run summaries and setup text.

README.md files explain directories and their conventions. Record descriptions
use `description.md`; release notes use the filename declared by their record.
