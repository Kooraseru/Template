# Language conventions

These files are reusable language and module-writing conventions. Start with [the language system](language-system.md) and [comments](comments.md), then read only the rules relevant to the source language and module responsibility.

- [Bash](bash/README.md)
- [CSS](css/README.md)
- [HTML](html/README.md)
- [JavaScript](javascript/README.md)
- [Luau](../../rules/luau/README.md)
- [Rust](rust/README.md)

No language becomes mandatory merely because guidance for it exists. Build systems and runtime ownership remain project-specific.

Guidance was adapted from [personal-global-rules at 514b3f1](https://github.com/Kooraseru/personal-global-rules/tree/514b3f147cb8f3956342a42a7227accc5fbb068e/global-rules/languages). The upstream validators and audit remain references for future integration.
