# 10.1.2026

Initial reusable repository template baseline.

## Added

- One GitHub Actions workflow, also executed locally through `act` and GitHub Local Actions.
- Declarative configuration, validation rules, publication policies, and test cases.
- 24 Linux image variants covering Alpine, Debian, Ubuntu, Fedora, and Arch with selected GCC, Clang, Rust, and MinGW profiles.
- 32 build targets, including native Windows and macOS on x86_64 and ARM64.
- Toolchain compilation probes, checked distribution manifests, and gated artifact publication.
- Authored Markdown release notes and optional build settings that can be omitted when unused.

## Fixed

- Native Windows Lune PATH setup and macOS checksum verification.
- Catalogue test fixtures now work independently of the selected target matrix.

## Using the template

Configure project build commands and package outputs for the consuming repository.
This baseline has no application-specific binaries. Release notes are authored
records; CI does not generate them from commit messages.
