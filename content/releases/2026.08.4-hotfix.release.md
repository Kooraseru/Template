# 2026.08.4-hotfix

## Summary

Restores GitHub license detection and limits generated GitHub configuration to
the default branch control plane.

## Notable Changes

- Publish the canonical root `LICENSE` directly in every generated payload.
- Publish root community-health files without copying the source README.
- Add root `CITATION.cff` metadata and publish it in every channel.
- Restrict `.github` publication to a deliberate `stable`-only allowlist of
  repository metadata, templates, workflow definitions, and their consumed
  configuration.
- Keep source ownership, scripts, publication internals, and dependency-review
  configuration out of preview channels and the stable control plane.

## Issues Addressed

- Addresses the stable branch omitting GitHub's detected License entry.
- Addresses generated branches receiving the entire authored `.github` tree.

## Compatibility

The canonical public control files move to GitHub-recognized source locations.
The license text and published user payload remain unchanged.

## Verification

- Publication tests verify channel-specific GitHub control-plane inclusion.
- Citation metadata and publication presence validation pass.
- Repository and Actionlint validation pass.
- Generated publication payload validation requires root `LICENSE`.
