# 2026.08.1-regular

## Summary

Initial release of the reusable repository template, including its authored
source model, generated publication channels, documentation, localization, and
validation automation.

## Notable Changes

- Establish `source` as the canonical authoring branch.
- Provide generated `canary`, `beta`, and `stable` publication channels.
- Add localized repository and Pages content with English fallback behavior.
- Add repository validation, publication boundary checks, and signed-release
  automation.
- Provide portable VS Code launch, task, extension, snippet, and MCP templates.

## Issues Addressed

- Establishes the initial public release baseline; no earlier tracked issues are
  closed by this release record.

## Compatibility

This is the initial release. Projects adopting the template must configure
repository environments, publication credentials, signing, Pages, and project
identity before publishing.

## Verification

- Repository contract validation passes.
- Localization and publication test suites pass.
- GitHub Actions workflows pass Actionlint validation.
- Local `canary`, `beta`, and `stable` payloads build successfully.
