# 2026.08.2-hotfix

## Summary

Corrects generated repository README placement so publication branches display
the localized release-facing README instead of the authored source README.

## Notable Changes

- Stop copying the canonical source-root `README.md` into publication payloads.
- Generate the English repository README at `docs/README.md` alongside the
  existing localized README files.
- Correct English repository README asset and repository-policy links for its
  location beneath `docs/`.
- Explicitly target the repository when dispatching the Pages refresh workflow.

## Issues Addressed

- Addresses the generated stable branch displaying the source authoring README.
- Addresses the post-publication Pages dispatch failing outside a Git checkout.

## Compatibility

No known compatibility impact. GitHub discovers `docs/README.md` as the
repository landing README when no root README exists.

## Verification

- Repository, localization, publication, and manifest tests pass.
- Actionlint validation passes.
- Local `canary`, `beta`, and `stable` payloads contain `docs/README.md` and
  `docs/README.ja-JP.md` and contain no root `README.md`.
