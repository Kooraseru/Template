# 2026.08.3-hotfix

## Summary

Removes conflicting GitHub-directory README content and completes the unified
local and GitHub workflow execution model.

## Notable Changes

- Remove `.github/README.md` so GitHub does not present competing README content
  alongside the generated repository README under `docs/`.
- Run local validation and publication through the same GitHub Actions workflow
  YAML used by GitHub.
- Remove the separate local-publication procedure.
- Make GitHub-only publication mutations report a clean local skip when the
  workflow runs through `act`.

## Issues Addressed

- Addresses conflicting repository README presentation caused by
  `.github/README.md`.
- Addresses drift between locally reconstructed commands and GitHub Actions.

## Compatibility

Local workflow execution now requires `act`. Focused component scripts remain
available for diagnosis, but they are not a separate publication workflow.

## Verification

- Repository, localization, publication, and manifest tests pass.
- Actionlint and VS Code task JSON validation pass.
- Generated publication payloads contain localized READMEs beneath `docs/` and
  no root repository README.
