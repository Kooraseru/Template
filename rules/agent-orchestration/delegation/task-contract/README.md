# Delegation task contract

Give every subagent one bounded objective, the relevant context, constraints,
and an expected handoff. Identify files or interfaces it owns when editing is
in scope. State whether the work is read-only or may change files.

Include the acceptance condition and any verification expected from the
subagent. Ask for findings with evidence and unresolved issues, not just a
completion claim. Keep ownership of final scope and priority with the
coordinating agent.
